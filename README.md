# Jarvis AI Desktop Assistant 🤖

A voice-controlled AI assistant built using Python that can perform system tasks and interact in Hindi & English.

---

## 🚀 Features
- 🎤 Voice recognition (Hindi + English)
- 🧠 Local AI using Ollama (LLaMA 3)
- 💻 Open apps & websites using voice
- 🗂️ File handling commands
- 🖥️ Futuristic GUI interface

---

## 🛠️ Tech Stack
- Python
- Tkinter (GUI)
- Whisper (Speech-to-Text)
- pyttsx3 (Text-to-Speech)
- Ollama (Local LLM)

---

```bash
git clone https://github.com/your-username/jarvis-ai-assistant.git
